Martin Bot平台使用指南 · v0.2

把工作区里的 Bot 展示给别人

Martin Bot 是从 OpenBot 改造的 Agent 工作台。可以创建多个 Bot、分配工具权限和发起会话。本版为个人和团队工作区增加了目录搜索与团队展示。

试用团队展示 →

先用一分钟体验

  1. 打开预览，勾选「客户支持」。搜索“出处”，再勾选「资料研究」。下面的名单按勾选顺序排列。
  2. 点「导出展示 HTML」，打开下载文件。用左右方向键或「下一页」逐一介绍。收件人可以直接打开同一份文件。
  3. 想改出场顺序时，取消勾选后重新选择。导出文件保存的是当时的名称、标题和职责；内容变化后可重新导出。

在实际平台里操作

进入工作区首页，点击「Martin Bot 工作台 · 管理与展示 Bots」，也可直接进入 /bots。在「查找工作区中的 Bot」输入名称、标题或职责，点击匹配项即可进入原有 Bot 详情。

点击目录中的「团队展示」展开选择器。这里读取你当前可见的 Bot。选中要给观众看的成员后，导出步骤与预览相同。展示文件只写入选中的名称、标题和职责。

运行 Web 平台

准备好 Docker、Bun 1.4.3，并按仓库 README 的 Run from source 配置 CopilotKit 连接及模型凭据。首次检出可从以下命令开始。

git clone https://github.com/MMMforY/Martin-Bot.git
cd Martin-Bot
cp .env.example .env
bun install

团队版使用默认配置。个人版可在启动前运行 bash scripts/use-personal-edition.sh。完成连接配置后运行 bash scripts/start.sh，浏览器打开 http://localhost:3010。
