Martin Bot使用指南

用一分钟展示一次会后跟进

解压展示包，双击同一文件夹里的 index.html。现场只需浏览器，断网也能操作。

打开会议工作台 →

现场怎么讲

  1. 先看原文。 打开后已有三项产品周会待办。展开第一项的「查看原文」，让观众核对“林夏”和“周五”的出处。
  2. 请观众改一项。 把会议记录里的“周五”改为“周四”，点击「整理清单」。第一项的期限会跟着变化。
  3. 补上缺失信息。 第三项只有测试名单，负责人和期限显示“待确认”。点进字段填写现场商定的人名和日期。
  4. 带走结果。 点击「导出 Markdown」，从浏览器下载中打开清单，即可看到刚才的修改。切换到「活动筹备」可以再演示一轮。

换成自己的记录

离线版按行整理，每行放一项待办，把会议标题和背景说明留在输入框外。下面这种句式可以自动拆出三个字段。

王琳负责准备客户访谈提纲，周四前完成。

只有任务时可写“待办：准备签到二维码”。修改原文后需要再点一次「整理清单」。重新整理会根据输入重建结果，刷新或关闭页面会清空本次修改，需要留存时先导出。

在 OpenBot 里使用模型版

Fork 的个人版配置包含 Martin Bot 和专用会话频道。完整克隆仓库后，按 README 的 Run from source 准备 Docker、Bun、CopilotKit 连接和模型凭据。配置好 .env 后运行 bash scripts/use-personal-edition.sh 切换到个人版，再运行 bash scripts/start.sh。

打开 http://localhost:3010，在 Bots 中选择 Martin Bot，贴入整段会议记录。模型会按 Bot 指令区分建议与已商定的任务，并引用原文。此模式的数据处理取决于所配置的模型服务。
