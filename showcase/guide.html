三分钟演示一个 Agent 工作区

双击同目录下的 index.html。从总览开始，让观众自己创建成员、分派任务，并决定一次文件操作是否通过。

打开工作台 →

从分派到交付

  1. 打开「Bot 目录」，点「新建 Bot」。名称填“发布协调”，职责填“汇总上线检查项”，创建后就能在目录中找到它。
  2. 在新成员卡片上点「分派任务」，保留“生成报告文件”，在素材里逐行写入两条真实想演示的事项，提交任务。
  3. 关闭任务详情，进入「审批收件箱」。打开刚提交的任务，核对原始素材并点「批准生成报告」，再点「下载报告」。打开下载文件，对照刚才输入的内容。
  4. 回到「工作区总览」，看审批数减少、已完成任务数增加。打开「活动记录」，查看创建、提交、审批和导出的顺序。

让观众试另一条路径

选「仅整理清单」可直接查看编号结果。拒绝文件请求后，可在「任务中心」的「已拒绝」筛选下找到它。打开「团队展示」，按出场顺序勾选 Bot，导出 HTML；用左右方向键翻页即可投屏介绍。

演示数据与部署

本文件使用浏览器本地数据演示任务生命周期，按行整理素材。无需账号、模型密钥或网络。浏览器允许时会保留修改；下一场演示可点「重置演示」恢复初始数据。

部署版在工作区首页和 /bots 提供目录搜索及团队展示。真实模型、工具调用和审批由配置好的 OpenBot 后端运行。按仓库的 Run from source 配置 Docker、Bun、CopilotKit 连接和模型凭据后启动。查看平台源码与部署说明 ↗
